# ⚙️ Koda Configuration

## 📁 Структура

```
.koda/
├── config.yaml              # MCP серверы (версионируется)
└── skills/                  # Скиллы (версионируются)
    ├── game-development.md
    ├── threejs-templates.md
    └── MCP-GAME-DEVELOPMENT.md
```

## 🎯 Где хранится

| Тип | Путь | Версионируется |
|-----|------|----------------|
| **Локальный конфиг** | `.koda/config.yaml` | ✅ Да |
| **Локальные скиллы** | `.koda/skills/` | ✅ Да |
| **Глобальный конфиг** | `C:\Users\Aleksey\.koda\config.yaml` | ❌ Нет |
| **Глобальные скиллы** | `C:\Users\Aleksey\.koda\skills/` | ❌ Нет |

## 🔧 Управление

### Проверка конфигурации
```bash
.\scripts\check-koda-config.ps1
```

### Синхронизация с глобальным конфигом
```bash
.\scripts\sync-koda-config.ps1
```

### Просмотр текущего конфига
```bash
Get-Content .koda/config.yaml
```

## 📦 Доступные MCP серверы

| Сервер | Назначение |
|--------|------------|
| Playwright | Тестирование браузера |
| Filesystem | Работа с файлами |
| Git | Контроль версий |
| GitHub | Issues, PR |
| Fetch | Документация |
| PostgreSQL | База данных |
| Memory | Кэширование знаний |

## 🎮 Доступные скиллы

| Скилл | Назначение |
|-------|------------|
| Game Development | Общие навыки Three.js, Cannon.js |
| Three.js Templates | Шаблоны кода |
| MCP Game Development | Документация по инструментам |

## 💡 Использование

Просто пиши в чате Koda задачи для игры:
- "Создай систему нитро с частицами"
- "Добавь новую трассу"
- "Оптимизируй рендеринг"

Koda автоматически использует локальные скиллы и MCP серверы из `.koda/`.

## 🔄 Обновление

Чтобы обновить скиллы или сервера:
1. Отредактируй `.koda/config.yaml` или `.koda/skills/*.md`
2. Перезагрузи Koda
3. Изменения применятся автоматически
