## 📖 Как создать новый скилл

1. Создай файл в `.koda/skills/my-skill.md`
2. Добавь frontmatter:
```yaml
---
name: My Skill
description: Описание
version: 1.0.0
---
```
3. Напиши контент (документация, шаблоны, инструкции)
4. Используй в запросах: "Используй скилл My Skill для..."

## 🔧 Как добавить MCP сервер

1. Отредактируй `.koda/config.yaml`
2. Добавь секцию:
```yaml
- name: My Server
  command: npx
  args:
    - -y
    - "@package/server-name"
  env: {}
```
3. Перезагрузи конфигурацию
